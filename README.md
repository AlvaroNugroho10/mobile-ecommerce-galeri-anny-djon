# Mobile E-Commerce Application for Galeri Anny Djon

A mobile e-commerce application developed for Galeri Anny Djon to support the sale and ordering of paintings and hand-painted products.

## 📱 About the Project

This project was developed as a final academic project at Universitas Brawijaya.

The application allows users to browse products, view product details, add products to the cart, place orders, and complete payments through an integrated payment gateway.

## ✨ Features

- User authentication
- Product browsing and search
- Product categories
- Product detail
- Shopping cart
- Checkout
- Midtrans payment gateway integration
- Order history
- Firebase Authentication
- Cloud Firestore database

## 🛠️ Tech Stack

- Flutter
- Dart
- Firebase Authentication
- Cloud Firestore
- Node.js
- Express.js
- Midtrans
- Figma

## 🎯 Project Purpose

The application was designed to provide a digital sales and ordering platform for Galeri Anny Djon, making it easier for customers to discover products and complete purchases through a mobile application.
